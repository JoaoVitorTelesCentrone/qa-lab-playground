### Slide 2
**#1** — Reage x previne
Manual espera o ticket. QA caça o bug antes dele virar incidente.

### Slide 3
**#2** — Clica x automatiza
Manual repete o teste na mão. QA escreve uma vez e roda mil vezes.

### Slide 4
**#3** — Tela x API
Manual confia no que aparece. QA valida o que a API realmente devolve.

### Slide 5
**#4** — Caminho feliz x edge case
Manual testa o óbvio. QA quebra com timezone, vazio, limite e duplicidade.

### Slide 6
**#5–7** — Acha x prova
QA documenta, classifica severidade e entrega evidência. Não é 'achismo'.
