# Piloto visual — carrossel 50

Cinco slides quadrados (1080 × 1080 px) sobre IA e julgamento em QA. A sequência usa a ideia de um dossiê de investigação: sinal de teste, pergunta, comparação e decisão. Mantém o verde e o fundo escuro do QA Lab, com páginas claras para marcar as viradas da narrativa.

Abra `preview.html` para avaliar a sequência. Os arquivos PNG estão nesta pasta; `build.mjs` e os HTMLs de cada slide permitem alterar texto e composição e exportar novamente com Chrome ou Edge.

O pedido duplicado é um exemplo didático fictício. Esta é uma proposta visual para avaliação, ainda sem revisão editorial final ou publicação.
