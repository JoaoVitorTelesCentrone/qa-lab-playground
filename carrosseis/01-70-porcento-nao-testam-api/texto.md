### Slide 3
**A ARMADILHA** — O caminho feliz é só 20%
Status code errado, contrato inconsistente, paginação que pula item. Os outros 80% quase ninguém testa.

### Slide 4
**POR QUE ACONTECE** — Teoria não pega bug
Curso de API ensina a sintaxe do request. Não ensina onde o bug costuma se esconder.

### Slide 5
**A SOLUÇÃO** — Treine em API quebrada de propósito
DELETE que não deleta. Health check mentiroso. Login sem rate limit. Bugs reais pra você caçar.

### Slide 6
**O MÉTODO** — Prove, não decore
Escreva o teste que confirma o bug. É assim que se vira QA de API de verdade.
