# Starter de comunicação ágil para QA

Modelos curtos para adaptar ao contexto do seu time. Não precisam virar burocracia: use só o que ajudar uma conversa a produzir entendimento, decisão ou próximo passo.

- `templates/refinamento.md`: perguntas, exemplos, riscos e dúvidas abertas.
- `templates/atualizacao-async.md`: contexto, evidência, impacto e pedido.
- `templates/handoff-bug.md`: observação reproduzível sem culpabilização.
- `templates/retrospectiva.md`: experimento pequeno e revisável.

## Como praticar

Escolha uma funcionalidade fictícia e preencha os quatro modelos. Peça a outra pessoa para ler sem contexto: ela consegue identificar a regra, o risco e o próximo passo? Encurte o texto até que consiga.
