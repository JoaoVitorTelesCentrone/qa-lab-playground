# Bug report track starter

Modelo e exemplos fictícios para o projeto final da trilha. Use somente em sistemas próprios ou ambientes de teste autorizados. Antes de compartilhar evidências, remova dados pessoais, cookies, tokens e segredos.

## Arquivos

- `templates/bug-report.md`: modelo reutilizável.
- `examples/confirmed-example.md`: relato reproduzível de exemplo.
- `examples/intermittent-example.md`: exemplo que registra frequência e limites da amostra.
- `checklist.md`: revisão rápida antes de enviar.

O starter não assume que a severidade determina prioridade. A prioridade depende do processo e contexto do time.
