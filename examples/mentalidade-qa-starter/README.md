# Caderno de prática: mentalidade de QA

Use estes prompts para registrar uma investigação ou revisar uma decisão. Eles não substituem conversa com o time nem exigem preencher todos os campos em todo trabalho.

## Roteiro

1. Descreva contexto e quem pode ser afetado.
2. Registre perguntas e hipóteses separadamente.
3. Escolha experimentos que possam diferenciar as hipóteses.
4. Anote o que observou, incluindo condições e limites.
5. Explique risco restante e próximo passo.
6. Depois, pergunte o que o sistema/time pode aprender.

Modelo editável em `templates/registro-de-investigacao.md`.
