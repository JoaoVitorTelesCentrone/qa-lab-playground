# QA metrics track starter

Material fictício para o projeto final da trilha. Os números não são benchmarks, metas recomendadas nem resultados reais do QA Lab.

## Arquivos

- `templates/scorecard.md`: estrutura para escolher sinais a partir de uma decisão.
- `metric-dictionary.csv`: exemplos de definições operacionais e suas limitações.
- `sample-releases.csv`: dados sintéticos para praticar cálculos por release.
- `examples/sample-scorecard.md`: leitura demonstrativa dos dados e perguntas para investigar.

## Como usar

1. Escolha uma decisão de qualidade que o time precisa tomar.
2. Selecione poucos sinais relacionados a resultado, risco e fluxo.
3. Defina coorte, numerador, denominador, unidade, janela, fonte e responsável.
4. Calcule uma linha de base antes de discutir metas.
5. Combine uma ação, uma contramétrica e uma data de revisão.

Não use os exemplos para ranquear pessoas. Atualize definições quando instrumentação, produto ou processo mudar.
